Python Core Syntax Rules

Click tabs to read

In Python, the print() command sends text to the screen console.

print("Hello, Python Coder!")
  • Python commands are case-sensitive (print is valid; Print causes a SyntaxError).
  • Text inside quotation marks is called a String.

Python handles numbers without quotation marks! If you enclose numbers in quotes, Python treats them as literal text. Without quotes, it does calculation math!

# String Text:
print("10 + 20")
Output: 10 + 20
# Math Calculation:
print(10 + 20)
Output: 30

Use special Escape Characters (starting with backslash \) or Triple Quotes to format text layout:

print("First Line\nSecond Line\tTabbed")
Notes: \n = Newline | \t = Tab Spacing
print("""Line 1
Line 2
Line 3""")
Notes: Triple quotes """ keep exact multi-line styling.

Use hashtags # for comments. Comments are ignored by Python and are used to leave helpful developer notes.

# This is a comment note
print("Executable code")
