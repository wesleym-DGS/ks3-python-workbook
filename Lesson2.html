Today’s goal

Give your code a memory.

Use variables to keep values, ask the user for input, and choose the right data type to work with their answers.

name = "Ada" · Variables

A variable is a named place to store a value. Use a clear name, then use that name to read or update the value later.

score = 10
score = score + 5
print(score) # 15

input() · Ask a question

The input() function reads text. Even if someone types a number, convert it with int() before doing number maths.

age = int(input("Age? "))
print(f"Next year: {age + 1}")

Choosing a data type

Text is a str, whole numbers are int, decimal numbers are float, and a yes/no value can be bool. Use type(value) to inspect a value while learning.
