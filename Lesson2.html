Quick reference

Variables, input & data types

Variables and assignment

A variable is a name that refers to a value. Assignment uses =: Python works out the expression on the right, then stores that result under the name on the left.

score = 10
score = score + 5
print(score) # 15

Choose names that explain the value, such as player_name or total_score. Names can contain letters, digits and underscores, but cannot start with a digit. Upper-case and lower-case letters are different.

Display values and build messages

print() displays values. Separate values with commas to include a space between them, or use an f-string to place a value or calculation inside a sentence.

name = "Ada"
age = 12
print("Hello,", name) # Hello, Ada
print(f"Next year, {name} will be {age + 1}")

The f before the opening quote tells Python to evaluate expressions inside braces, such as {age + 1}. Without the f, the braces are just printed as text.

Ask for input while the program runs

input() displays an optional prompt, pauses the program, and returns what the user types as text (str). Save the answer in a variable so you can use it later.

name = input("What is your name? ")
print(f"Hello, {name}!")

When you run this program, enter your answer in the terminal input box. The answer can be different each time without changing your code.

Choose the right data type

A value's type determines how Python can use it. Common types are text (str), whole numbers (int), decimal numbers (float) and true/false values (bool).

age = int(input("Age? "))
height = float(input("Height in metres? "))
print(type(height)) # <class 'float'>

int() converts suitable text to a whole number; float() converts it to a decimal number. str() converts a value to text, and type() helps you inspect a value.

Do calculations with numbers

Python can calculate with numeric values and store the result. A value from input() must be converted before it can be used as a number.

age = int(input("Age? "))
next_year = age + 1
print(f"Next year: {next_year}")

Useful operators: + add, - subtract, * multiply, / divide, // whole-number division, % remainder and ** power.
