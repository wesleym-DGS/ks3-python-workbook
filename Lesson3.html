Today’s goal

Make decisions with code.

Use conditions to let a program choose what to do. Compare values, follow the correct branch, and test your program with different answers.

Quick reference

Selection and conditions

Conditions and comparisons

A condition is a question Python can answer with True or False. Comparison operators let you check whether values are equal, different, greater, or less.

score = 72
print(score >= 50) # True
  • == equal to, != not equal to.
  • > greater than, < less than, >= greater than or equal to, <= less than or equal to.
  • Use == to compare values. A single = assigns a value to a variable.

Choose with if and else

An if statement runs its indented block when its condition is true. An optional else block runs when that condition is false.

temperature = 24
if temperature > 20:
print("Warm day")
else:
print("Cool day")

The colon starts each branch. Indentation (usually four spaces) shows which statements belong to that branch. Exactly one branch runs in this example.

Choose between several options

Use elif (short for “else if”) to test another condition when the earlier one was false. Python checks from top to bottom and runs the first matching branch.

if mark >= 80:
print("Great work")
elif mark >= 50:
print("Pass")
else:
print("Keep practising")

Order matters: check the highest mark first. If you checked mark >= 50 first, a mark of 90 would match that branch and never reach the 80-point option.

Combine conditions with and and or

and needs both conditions to be true. or needs at least one condition to be true. Use brackets to make longer conditions easier to read.

if age >= 13 and has_ticket:
print("You may enter")
if day == "Saturday" or day == "Sunday":
print("It's the weekend")

Trace and test a decision

Before running code, try a value exactly on each boundary and follow the conditions in order. Then run the program with several values to check every outcome.

  • Check every if, elif and else ends with a colon.
  • Indent the statements inside each branch by the same amount.
  • Use == for equality comparisons; do not confuse it with assignment =.
  • Try values below, on, and above a threshold to catch boundary mistakes.
