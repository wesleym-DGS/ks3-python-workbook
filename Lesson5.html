Quick reference

While loops and counters

A while loop repeats while its condition is true

Python checks the condition before each loop round. The indented statements repeat while it is True; when it becomes False, the program continues after the loop.

count = 3
while count > 0:
print(count)
count = count - 1

This prints 3, 2, 1. The counter changes each round, so eventually the condition is False. If the counter never changes toward the stopping condition, the loop may never end.

Counters track what has happened

A counter starts at a known value and is updated during a loop. A question counter increases every round; a correct-answer counter increases only when the answer is right.

questions = 0
questions = questions + 1
correct = correct + 1
  • Initialise counters before the loop.
  • Update a question counter on every round, inside the loop.
  • Update a correct counter only in the correct-answer branch.
  • Indentation determines whether a statement repeats or runs once after the loop.

Trace one round at a time

Record the line being run, counter values, and output. At the end of each loop round, check the condition again using the updated values.

Test boundary cases: the first count, the last count, and the value that makes the loop stop. Use the Stop button if a loop does not finish as expected.
