Python Core Syntax Rules

Click tabs to read

Use print() to display information. Put text in quotation marks; separate multiple values with commas.

print("Hello, Python Coder!")
Output: Hello, Python Coder!
print("Score:", 15)
Output: Score: 15
  • Text inside quotes is a string. Single and double quotes both work: 'Hi' or "Hi".
  • Python is case-sensitive: print works, but Print is a different name.

Numbers without quotes can be calculated. Put a number in quotes and it becomes text, so Python displays the characters instead of doing arithmetic.

# Text, not a calculation
print("10 + 20")
Output: 10 + 20
# Calculate with numbers
print(10 + 20)
Output: 30

Arithmetic operators

  • + add, - subtract, * multiply, and / divide.
  • // gives whole-number division, % gives the remainder, and ** raises a number to a power.
print(17 % 5)
Output: 2 because 5 goes into 17 three times, with 2 left over.

A backslash inside a string starts an escape code, which represents a character that is awkward to type directly. Triple quotes let a string span multiple lines.

print("First line\nSecond line\tIndented")
Result: First line, then a new line; the second line begins after a tab.
print("""Notice
Doors close at 9
Please arrive on time""")
  • \n starts a new line; \t adds a tab space.
  • Use matching pairs of three single or double quotes to write a multi-line string.

A # comment is a note for people reading your program. Python ignores everything from the hash to the end of that line.

# Print a message for the user
print("Ready to learn!") # Python runs this part

Quick checks when code will not run

  • Check that every opening bracket has a matching closing bracket.
  • Check that strings have matching quote marks and that print is lower-case.
  • Keep comments on their own line or after code; a comment does not display as program output.
