Quick reference

More branches and iteration

Choose one matching branch

Python checks an if/elif chain from top to bottom and runs the first branch whose condition is True. The optional else handles every remaining case.

if weather == "rainy":
advice = "Take an umbrella"
elif weather == "snowy":
advice = "Wear warm clothes"
else:
advice = "No special advice"
print(advice)

Consecutive if statements are different: each condition is checked, so more than one block can run. In an if/elif/else chain, at most one branch runs.

Repeat with while

A while loop repeats its indented block while its condition is True. The condition is checked before each round, so update the values it depends on to make the loop finish.

name = input("Who are you? ")
while name != "Ada":
print("Try again")
name = input("Who are you? ")
print("Hello, Ada!")

The loop stops when its condition becomes False. If the condition never changes, the loop may run forever; make sure each round can move toward the stopping condition.

Trace and test

Follow one instruction at a time: check the condition, take one branch or loop round, update variables, then check again. Test each branch and both the continuing and stopping cases.

  • Put the most specific or highest threshold first in an if/elif chain.
  • Use == to compare values, and a single = to assign one.
  • Indent every statement that belongs to a branch or loop.
  • Test values below, on, and above boundaries; trace every loop check.
