Today’s goal

Plan it, repeat it, finish it.

Bring sequence, selection and iteration together to make a number guessing game. Use a Boolean flag to remember when the number has been guessed, and add a counter and clear feedback to help the player.

Quick reference

Loops, flags and decisions

A Boolean flag records yes or no

A Boolean value is either True or False. Set guessed to False before the game; change it to True only when the player finds the number.

guessed = False
while guessed == False:
# Ask, check, and update guessed

The loop repeats while its condition is True. Changing the flag lets the game stop.

Conditions choose what happens

Use if, elif and else to respond to different guesses. The comparison operators ==, < and > compare values. The logical operator and combines two conditions.

if guess == lucky:
# Correct guess
elif guess < lucky:
# Guess was too small
else:
# Guess was too large

A counter keeps track

Start guesses at 0, then add 1 each time the player enters a guess. A condition such as guesses < 3 can limit the number of turns.

Indentation controls which code repeats. Keep the final message outside the loop. Test a low guess, a high guess, a correct guess, and the maximum number of wrong guesses.
