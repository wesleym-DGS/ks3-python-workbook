02 / Learn

Meet HTML

HTML stands for HyperText Markup Language. It tells a browser how to structure a web page: which parts are headings, paragraphs, lists and more. A static web page can be stored as a plain-text HTML file.

<p>Opening tagContent</p>Closing tag

Tags use angle brackets. Many have an opening and a matching closing tag; the closing tag includes a forward slash. Tags can also be nested inside each other. Some tags, such as <br>, do not have a closing tag.

Useful building blocks
HTMLWhat it does
<h1>Title</h1>A main heading; h2 can be used for a subheading.
<p>Hello!</p>A paragraph.
<em>important</em>Emphasises text, usually in italics.
<b>bold</b>Draws attention to text, usually in bold.
<q>words</q>Marks a short quotation.
<ul><li>One</li></ul>A bulleted list with a list item.

Only content inside a tag receives that tag's formatting. For example, Building <b>web pages</b> displays as Building web pages.

04 / Experiment

Style it up

HTML tags can also have a style attribute. This is called inline styling: it changes that particular element.

<h1 style="color:red;text-align:center;">Developing for the Web</h1>

Each declaration has a property, a colon and a value; separate declarations with semicolons. Use color, not colour, in code. Changing many individual tags this way takes time; later you will learn how CSS can help.

Try the styling worksheet

Continue your page in the editor above. If you need a starting point, choose Load tagged starter first.

  1. Make the first heading red and centred using the example above.
  2. Experiment with font-family:Verdana;, font-size:25px;, border:1px solid blue; and background:lightblue;.
  3. Add a style to the <body> to give the page a common appearance. Then give an individual element a different font or colour. What happens?
Why can one element look different from the body?

Some properties, such as text colour and font family, can be inherited from the body. A value set directly on an element can override the inherited value. Not every CSS property is inherited.
