02 / Learn

One stylesheet, many rules

CSS separates presentation from page structure. A rule has a selector that chooses elements and declarations inside braces that set properties and values.

h1 {
  color: darkgreen;
  text-align: center;
}

A type selector such as h1 targets every matching heading. A class selector such as .highlight can be reused on selected elements. Put shared rules in one stylesheet and link it from each page with a <link rel="stylesheet" href="style.css"> element.

Why is this a shortcut?

A single shared rule can format many elements. Updating it once is more consistent than editing repeated style attributes one by one.
