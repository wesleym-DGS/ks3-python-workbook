01 / Think first

Make a query more precise

02 / Learn

Search with a purpose

Useful searches describe the information you need. Add specific keywords, put an exact phrase in quotation marks, or exclude a word with a minus sign when a search tool supports those features. Check the source, date, and purpose of a result before relying on it; a high position alone does not prove that it is accurate.

A hyperlink uses an anchor element and an href destination. A relative destination such as about.html points to another file in the same folder.

<a href="about.html">Read about the project</a>

03 / Investigate

Improve the search

This small offline index matches every word and ranks title matches more highly. Try adding a specific word to narrow the results.

  1. A field guide to mammals, birds, and insects found in British woodlands.
  2. Common garden wildlife and how to observe it safely.
  3. A family walking route through a forest with a map.
  4. How habitats provide food and shelter for wild animals.

No indexed pages match every word in this query.
