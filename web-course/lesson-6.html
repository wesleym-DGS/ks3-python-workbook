01 / Plan

Design for a visitor

Choose a topic and plan three related pages: a home page, a detail page, and a gallery or resource page. Give each page a clear purpose and plan a navigation menu that appears consistently.

02 / Learn

Make a set of pages feel like one site

Save each page as a separate HTML file in one folder. Use relative links such as about.html to connect files in that folder. Repeat a navigation menu on every page, make link text describe its destination, and use the same stylesheet so the pages feel related.

Before sharing a site, test every link, image path, heading order, and text alternative. A visitor should be able to understand where they are and how to return to the home page.

03 / Create

Build your three-page website

Adapt the three starter files below. Change the page names, content, image paths, navigation destinations, and CSS to fit your plan. Preview the home page here; download each file and place them together in one folder to test the complete site.
